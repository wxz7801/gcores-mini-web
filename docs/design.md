## 0. 手机竖屏（v3）：照搬机核 App 的结构

v2 的左侧 64px 竖条已去掉，左侧禁区规则只用于横屏。手机端按机核 App 的「播客」页和播放页来做：

- 首页（「播客」）：大标题 + 右上角队列、搜索；横滑 chips（全部 / 免费节目 / 有声书 / 会员节目 / 各栏目）；顶部推荐横幅；栏目图标宫格（可展开）；「GPASS 会员」「播单」横滑卡片区，带「查看更多」；最新节目列表。
- 底部 Tab：首页 / 栏目 / 播放中 / 有声书 / 我的。中间的「播放中」代替迷你播放器，Tab 栏上沿用一条细线显示播放进度。
- 播放页：上方是时间轴信息流（每段一个「▶ 标题 时间」胶囊 + 配图卡片 + 文字，点胶囊跳到该时间点）；顶部中间是「返回当前播放」（手动滚动离开当前段落后出现），右上角分享。
- 底部播放面板（可上拉/下拉）：进度条（金色刻度标出时间轴节点）、-15 / 上一段 / 播放 / 下一段 / +15，下面一行是点赞数、倍速、评论数、播放列表、收起。
- 和 App 不同的地方：「上一段 / 下一段」跳的是时间轴段落，不是上一期 / 下一期节目；所有按钮热区 ≥ 48px。

## 1. 核心约束：左侧禁区（仅横屏）

横屏（平板 / 车机）时，UI 最左侧不放任何可交互元素。

| 形态 | 禁区宽度 | 禁区里放什么 |
| --- | --- | --- |
| 平板 / 车机横屏（≥ 900px 宽） | 左侧约 1/3「舞台区」 | 正在播放的封面、当前时间轴配图与文字、下一段预告，全部只展示 |

实现规则：

- 用一个 CSS 变量 `--dead-zone` 统一控制禁区宽度，所有可点元素的 `left` 都 ≥ 这个值。
- 禁区容器设置 `pointer-events: none`，从实现上保证误触不会触发任何操作。
- 横屏下内容区里的列表行正常整行可点（禁区已经把左侧让出来了）。
- 返回、收起、搜索、设置统一放右上角。
- 导航：横屏用右侧竖向导航栏。
- 横向滚动的 chips 和时间轴卡片从禁区右侧开始，滑动起点也不在禁区内。
- 开发时加一个调试开关，把禁区用黄色斜纹标出来，方便自查。

## 2. 布局断点

| 断点 | 布局 |
| --- | --- |
| < 600px 竖屏 | 机核 App 式布局：单列 + 横滑卡片区 + 底部 5 Tab |
| 600–899px | 两列网格，其余同竖屏 |
| ≥ 900px 横屏 | 舞台区（33%）\| 内容区（自适应）\| 右侧导航栏（92px）；播放条固定在内容区底部 |
| 车机模式（横屏 + 手动开关或 `?car=1`） | 触控目标从 48px 提到 64px，字号 +2，隐藏评论、简介等长文本，取消所有手势，只保留按钮 |

## 3. 触控规范

- 触控目标：普通按钮 ≥ 48px，主播放键 竖屏 60px / 横屏 80px，车机 ≥ 64px。
- 进度条：可拖动的热区高 ≥ 32px；拖动时放大滑块并显示目标时间；时间轴节点用金色短刻度标在进度条下方。
- 手势：上滑展开播放器、下滑收起；每个手势都有对应的可见按钮。车机模式下关闭手势。
- 颜色：深色背景；机核红 `#ff3e4d` 只用于播放状态和当前选中项；金色 `#f5c542` 只用于时间轴。

## 4. 登录页

- 二维码放在左侧舞台区，因为它只需要被扫描，不需要点按，正好符合禁区规则。
- 右侧放手机号 + 密码表单和「刷新二维码」按钮。
- 竖屏：二维码在上，表单在下；手机上通常无法扫自己屏幕上的码，所以竖屏默认显示密码登录。
- 页面上注明：短信验证码登录和第三方账号登录暂不支持。
